# Delegering av Kongens myndighet etter lov 4. desember 1992 nr. 127 om kringkasting og audiovisuelle bestillingstjenester (kringkastingsloven) til Kultur- og likestillingsdepartementet

Kongens myndighet etter lov 4. desember 1992 nr. 127 om kringkasting og audiovisuelle bestillingstjenester (kringkastingsloven) delegeres til Kultur- og likestillingsdepartementet for så vidt gjelder fastsettelse av forskrifter.
