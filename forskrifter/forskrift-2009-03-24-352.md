# Vedtak om fastsettelse av alternativ instrumentidentifikator

Med alternativ instrumentidentifikator etter forskrift til verdipapirhandelloven § 10-39 (b) menes: AII Exchange Code AII Exchange Product Code AII Derivative Type AII Put/Call Identifier AII Expiry/Delivery/Prompt Date AII Strike Price.
